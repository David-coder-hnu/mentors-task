# Stage 2 RouterShim：六行基线结果与 Agent 接线状态

日期：2026-11-10

范围：`RouterShim` Response 层合成测试床

状态：**基线可跑完；A1/A2 尚未形成完整正式表**

## 1. 这次完成了什么

`src/experiment/stage2.py` 把 Stage 1 的 32 个前缀与四档响应率叠加到一个显式
合成拓扑上：

- 8 个 aliased 前缀各暴露 1 个来源；
- 21 个会响应的非 aliased 前缀各暴露 3 个来源；
- 3 个沉默前缀没有可达来源；
- 真值共 71 个路由器。

同一个 `RouterShim` 同时生成 `Response` 与 `Stage2Truth`。所有策略经原有进程边界
运行，评分只发生在 runner 侧。Stage 2 新增：

- `true_routers`：首次出现的真实路由器实体数；
- `router_entropy_bits`：已观察来源的经验熵，作为次要诊断；
- 重复来源数、未知来源数、直接响应数和逐 seed 的 aliased 端点。

## 2. 六行基线

规模：6 策略 × 30 seeds × 1,000 探 = 180,000 探。每趟预算均为 1,000，
`charged=probes_run` 全部对账通过。总墙钟 **21.08 秒**。

| 策略 | `true_routers` mean ± SD | `aliased_waste_ratio` mean ± SD | caught mean |
|---|---:|---:|---:|
| B0 全探 | 54.000 ± 2.407 | 0.250000 ± 0.000000 | 0 |
| B1 均匀随机 | 53.467 ± 2.330 | 0.253267 ± 0.014188 | 0 |
| B2 响应密度贪心 | 29.833 ± 2.984 | 0.578267 ± 0.016903 | 8 |
| B3 bit-reversal | 55.133 ± 3.003 | 0.256000 ± 0.000000 | 8 |
| B4 响应率 bandit | 28.933 ± 2.504 | 0.511167 ± 0.011161 | 8 |
| B5 6SEVEN dealiasing + 发现分配 | **56.600 ± 2.191** | **0.204800 ± 0.003690** | 8 |

预注册的两条诊断比较（同一 seed 配对 Wilcoxon，Holm 校正两条）：

- `B5_vs_B2`：`true_routers` 平均高 **26.767**，Holm `p=3.46e-6`；
  waste 平均低 **0.3735**，Holm `p=3.63e-6`。
- `B5_vs_B4`：`true_routers` 平均高 **27.667**，Holm `p=3.46e-6`；
  waste 平均低 **0.3064**，Holm `p=3.63e-6`。

这些差异首先说明测试床能把“响应很多”与“实体很多”分开：B2/B4 追着高响应率，
在 aliased 前缀上花了约一半以上预算，只发现约 29 个路由器；B5 同时做
dealiasing 与发现分配，发现约 57 个路由器。**它们不是外部互联网有效性的证据。**
本轮只比较 6 条非 Agent 基线，不启用设计文档中完整八行表的 28 次比较族。

## 3. A1/A2 接线

协议已升到 v4：

- 策略进程发出 `decide(prompt, state, tool_pool)`；
- 决策缓存与 completion 都在 runner 侧；
- 策略进程只收到模型原文；
- 显式缓存文件路径会加入子进程沙箱的受保护根。

动作层与报告层：

- `construct` + `balanced_probe` 白名单复合原语；
- A1/A2/A3 预算耗尽后由同一确定性规则生成最终声明，不再额外调用模型。

当前 `construct` 是安全编译的声明式复合动作，**不是任意 Python 执行**。因此它已经
证明了开放动作空间可以接线，但还不能把 P1 的“构造任意新原语”部分宣称为完成。

确定性端到端验证：

- A1/A2 各 200 探，均花完预算；
- 首次运行 4 次决策，全部未命中；
- 同缓存回放 4/4 命中；
- 两次运行的 waste、router 数和信息量逐项相同。

真实模型验证：

- 通过本地 Responses API completion 适配器，seed 0、预算 100 的 A1 完成并回放
  2/2 决策；
- A1 的预算全投给一个 aliased 前缀：1 个路由器、waste=1.0、正确抓住 1 个
  aliased 前缀、漏掉 7 个；
- 旧版 A2 的最终声明调用曾在两次重试中超过 300 秒会话上限。该调用已由
  三行共用的确定性报告规则移除；新的 30-seed fixture 预检和 900/900 缓存回放
  见 `docs/results/t16-engineering-2026-11-10.md`。

这不是“A1 输给 B5”的结论。A1 的这条只是 100 探接线冒烟，规模与完整性都不满足
主表要求。
