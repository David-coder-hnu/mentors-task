## 预注册比较

配对 Wilcoxon signed-rank，Holm–Bonferroni（2 个比较）。

### M2 vs B4

- waste：M2 − B4 平均 **+0.225444**；
- 校正后 p = `5.393876929592027e-6`；
- rank-biserial = `1.0`；
- caught：平均 +0.1，校正后 p = `1.0`；
- 共同主端点判决：**B4 胜**。M2 在 waste 上显著更差，caught 没有显著改善。

### M2 vs M1

- waste：M2 − M1 平均 **+0.225111**；
- 校正后 p = `5.393876929592027e-6`；
- caught：两者 30 个 seed 都是 8，p = `1.0`；
- 共同主端点判决：**M1 胜**。M2 的历史记忆只增加了浪费，没有增加识别。

## 解释

在这个 Stage 1 封闭动作空间里，B4 和 M1 的行为几乎一致：都会把约 48% 的预算
投入 aliased 前缀，同时识别出全部 8 个 aliased 前缀。M1 的冷启动结果说明，
Stage 1 的这一现象不需要跨 run 记忆就能出现。

M2 从第二个 seed 开始使用先前历史，浪费率进一步上升到约 71%。记忆并没有让
策略“绕开已识别的陷阱”，反而让高响应前缀更容易持续吸走预算。这是对
“有记忆会改善探测”的直接反例。

## 边界

- 这是 Stage 1、当前 config、Punching Bag 响应模型下的结果；
- 不回答开放动作空间的 P1；

- M2 的负结果只说明当前 UCB1 记忆设计，不是对所有 Agent 记忆机制的一般结论。
