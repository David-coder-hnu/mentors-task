## Key Interactions to Verify

- `probe()` → 并发探测池 → 回包按 `(dst, icmp_id/seq)` 匹配 → `Response`：并发下不得串包
- `probe()` → 三态返回（`received` / `sent_no_reply` / `send_failed`）：**发包失败不得与对端不回包合并**
- `sample(prefix, n)` → 批量探测 → 聚合：粒度改变时结果应单调，不应出现非单调跳变
- `report(prefix, aliased)` → 声明通道 → `aliased_caught`：**评分器不得从行为里推断这个声明**
- `decide()` → 缓存查询 → （未命中）LLM → schema 校验 → 动作：**改 prompt 内容后必须缓存未命中**
- `state` 规范化 → 缓存键计算 → 命中/未命中：**同一 seed 重跑必须全部命中**（这是可复现性的定义）
- 预算台账（runner 侧权威）→ epoch 粒度预留 → 策略侧只读视图：**策略侧不得能改这个计数器**
- `score()` → 读 `Oracle.ground_truth()` → 指标：策略侧不得出现在这条链路上
- `stats.py` 配对检验：同一份合成数据上，配对检验的功效应高于原 CI 不重叠判据

## Edge Cases

- 靶场队列满丢包（实收 < 已发）→ 必须报错并使该次运行**无效**，不得把差值当超时
- **探测池大小漏传**（无默认值，v6）→ 必须显式报错，不得回退到一个默认值
- 迟到回包归属于错误的探测 → 必须被 `(dst, icmp_id/seq)` 匹配挡住
- 无 `CAP_NET_RAW` / 无路由 → 发包失败必须显式报错（`send_failed` + `error`），不得静默超时
- LLM 返回畸形 / 越界 dict → schema 校验必须拒绝并记录
- 前缀 `rate == 0` 与「前缀不在 config 里」→ 必须是两个不同的集合，不得合并
- 全 aliased 拓扑 → 评分器必须判定探测全部浪费
- 全非 aliased 拓扑 → `aliased_waste == 0`
- **策略侧试图读取真值字段**（D7）→ 必须失败（**进程边界**；类型断言退路已删除）
- **策略进程试图读 `config/`**（v6 / T10）→ 必须失败（`config/` 就是 `GroundTruth` 的来源）
- **策略进程试图读决策缓存文件**（v6）→ 必须失败（缓存里存着别的策略的决策）
- **并发下 `state` 的到达顺序扰动**（D9）→ 规范化后缓存键必须不变
- **同一状态在两个 `PYTHONHASHSEED` 下算出的缓存键**（v6 / 缓存 bug 4）→ 必须相等；用内建 `hash()` 会静默永不命中
- **留出集与调参集相交**（v6 / T18）→ 必须断言失败（前缀集合 / aliased 分布 / 响应率分布三者）
- **B0「全探一遍」拿到接近最优分**（D10）→ 触发退化警报，不得静默通过

## Critical Paths

- **Stage 1 冒烟运行**：**5 策略（B0/B1/B4/M1/M2）× 300 探测 × 30 seeds** 能跑完、能对账、能产出带配对检验结果与每 seed 分布的表。
  > **v6 更正**：上一版写「8 策略（B0–B5、A1–A2）× 1000 探测 × 30 seeds」——**两处都错了**。完整八行表归 Stage 2（C12）；Stage 1 是冒烟规模，且 A1/A2 在 Stage 1 **不参赛**（只构建、不上场）。
  > **挂钟上限**：`Σ(探测数 / epoch_size × W) + 并发后的包时间 + LLM 往返延迟`，随 config 一起冻结；**超了是配置错了，不是机器慢**。
- **Stage 2 全量运行**：**8 策略（B0–B5、A1–A2）× 1000 探测 × 30 seeds**，含 6Sense 独立轨道与 Holm–Bonferroni 校正 —— **分母 28（当前生效值；A3 重设计完成后为 30，A3 升为平权则为 36）**。
- **重跑可复现**：同一 config + 同一 seed 重跑，**靶场日志里被决定回应的包集合精确相等**（规范侧，进 CI）；容器环境侧容差 ≤1% 计数差 / 缓存命中率 100% / 拥塞余量 ≥2×。
- **真值不可达**：从策略侧出发，不存在任何路径能读到 `GroundTruth`（进程边界 + `config/` 黑名单 + 缓存文件黑名单，三条各有测试）。
- **Stage 2 shim 契约**：合成 `Response` 的 `src` 集合 == `GroundTruth.routers`，逐字段比对通过。
- **原语构造实验**：A1 在构造场景上必须失败（否则场景无效）、A2 的成败须由非场景作者裁决。
- **对等投入协议可审计**（v6 / T19）：同预算 / 同信息 / 同工具池 / 同裁决人，四条都要写出**怎么核对**。
